# 题库导入格式

导入入口：练习页 → 导入题库。四种格式自动按扩展名识别。

## Excel (.xlsx)

SheetJS 解析。列名（表头行）：

| 模块 | 题型 | 考点 | 题干 | A | B | C | D | 答案 | 解析 | 来源 |
|---|---|---|---|---|---|---|---|---|---|---|

题型填：单选 / 多选 / 判断。判断题 A、B 两列填 对、错（或留空）。

## JSON (.json)

数组，每项：

```json
{ "module":"行测", "question_type":"单选", "exam_point":"基期现期",
  "stem":"题干", "options":["A. …","B. …"], "answer":"B",
  "analysis":"解析", "source":"2024国考" }
```

## Markdown (.md) / 文本 (.txt)

同一语法，空行分题：

```markdown
# 模块:行测 题型:单选 考点:基期现期

2023年某市GDP为5000亿元，同比增长10%
A. 4500亿
B. 4545亿
答案: B
解析: 基期=现期/(1+r)
来源: 2024国考
```

解析规则：

- `#` 行设置模块/题型/考点，其后所有题继承，中途可再设。
- 题号（`1.` `2、`）自动去除；markdown 加粗、引用符号自动清理。
- **答案推断题型**：`ABD` 多字母→多选；`对/错`→判断；单字母→单选。
- `答案:` / `答案：` / `answer:` 均可。

## 背诵卡批量导入

背诵页「＋新卡」内：每行一张，格式 `正面|背面`（半角/全角竖线均可）。
