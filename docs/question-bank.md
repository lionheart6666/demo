# 静态真题库

## 来源

GitHub 开源仓库 [ERRRC/xingcezhenti](https://github.com/ERRRC/xingcezhenti)：2016-2026 年国考+省考行测真题，含官方解析。原始格式为 Obsidian Markdown（每试卷一个 md，分六大模块目录）。

## 覆盖范围

仅行测六模块：政治理论 / 常识判断 / 言语理解与表达 / 数量关系 / 判断推理 / 资料分析。
申论（主观题）与金监局专业课（官方不公布真题，只有考生回忆版）不在此库，走「导入题库」手动录入。

## 申论题库（data/bank/shenlun.json）

来源：开源仓库 [wunian-10086/kaogong-shuati](https://github.com/wunian-10086/kaogong-shuati) 的 banks-1/2/3/5.js（subject=申论），转换脚本 `convert_shenlun.py`（中间产物）。

结构：套卷数组，每卷含 materials（材料名+全文）、questions（题号/题型/题干/分值/字数建议/参考答案/阅卷要点 points）。
内容：13 套国考申论真题（2022-2025，副省级/地市级/行政执法）+ 申论100题，共 164 题。

交互规则（申论为主观题，不走判分）：材料 chips 阅读 → 自写作答（textarea 或纸上）→ 对照参考答案 → 勾选阅卷要点自查（勾中 ≥80% 视为要点找全）→ 记入练习记录（records，qid 前缀 `sl:`）。

## 转换管线

`convert_bank.py`（中间产物，不入库）：
1. 解析每份 md 的 YAML frontmatter（试卷/年份/模块）；
2. 按 `## 第 N 题` 切题，提取 qid（去重）、子题型标签、题干、选项（✅ 标答案）、官方解析；
3. `## 材料 N` 段落前置拼入其后各题题干（资料分析必需）；
4. 答案多字母→多选，单字母→单选；
5. 图片路径 `../90-图片/X` 重写为 `data/img/X`；
6. 按 `模块·子题型` 聚合输出 `data/bank/{考点}.json`，并生成 `manifest.json`（考点→{文件,题数,模块}）。

复跑前提：`xz_bank` 仓库在本地且已 sparse-checkout 全部目录。

## 金监局题库（data/bank/金监_*.json）

来源：`2025年金管局考前必刷500题-计算机岗` PDF（带水印扫描版），经 `pdfplumber` 抽文本后按考点切分。

管线要点：
1. 按「第一部分 试题部分 / 第二部分 解析部分」定位，再按「一、单项选择题 / 二、多项选择题」切段；**题干与答案都按段内编号对齐**（两段编号各自从 1 开始）。
2. 水印（喵/试/考/糖）、页眉页脚、页码按行清洗；同一编号出现多条答案时取与题干关键词重合度最高的一条。
3. 关键词加权分类到 20 个考点（一个考点一个文件），无匹配则不入库，不兜底到某个考点。

覆盖：20 个考点、506 题（单选 401 / 多选 105），manifest 的 `g` 字段直接写 APP 组名（计算机系统/操作系统/计算机网络/数据结构与算法/数据库/程序设计语言）。

## 加载机制

- 启动时仅 fetch `manifest.json`（小），练习页考点计数 = 用户题数 + 库内题数。
- 进入某考点刷题时才 fetch 该考点 JSON（最大约几 MB），内存缓存，不落地 localStorage。
- 错题以快照（qsnap）存入用户数据，与题库无外键依赖。
- 图片存于 `data/img/`（题目图/公式图），由静态服务器直接提供；含 `<img>` 的题干/解析经 `rich()` 直出 HTML。
