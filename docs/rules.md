# 业务规则

产品逻辑内核，全部来自用户已验证的刷题方法论（UP 主总结，出处标注于技巧库）。

## 判分

- 单选/判断：与标准答案一致得分，否则 0 分。
- **多选：所选集合与标准答案集合完全一致才得分**（少选/多选/错选均 0 分）——金监局专业课硬规则，基线痛点（20 题只得 2 分）。
- 偏题过滤：`pass_rate` 在 0~0.2 之间的题不进刷题池。

## 过关判定

- 10 题一组（`GROUP_SIZE`）。
- 每组结束显示正确率；**连续 3 组 ≥ 目标正确率（默认 80%）→ 该考点标记过关**。
- 中途未达标则连续计数清零重计。

## 计时与组卷

- 每道题单独计时，顶部实时显示；**单题超 2 分钟**弹提示条，建议标记跳过（每题只提醒一次）。
- 组结算显示：总用时、平均每题、超时题数；20 题以上或弱项组卷额外给出速度/正确率诊断。
- **错题重做**：用错题快照重新组卷，隐藏答案；目标 90%；答对自动移出错题本，答错累计次数。
- **弱项组卷**：取最近 15 组中正确率 <80% 的考点题 + 错题，共 20 题；不足时随机补真题库考点。

## 打卡与每日计划

- 打卡记录写入 `checkins`（日期数组），连续天数按日期倒推计算。
- 今日计划四项：打卡 / 刷一组题 / 错题重做 5 题 / 背诵到期卡，状态由当天数据自动判定。

## 错题本

- 错题 + 「拿不准」标记题**自动收录**（快照式）。
- 错因四类：概念不清 / 记错 / 粗心 / 方法缺失。
- 错两次标红（思维惯性错，需打破重立）。
- 复盘优先于刷新题：复盘时间应 ≥ 做题时间 2-3 倍。

## 背诵（艾宾浩斯）

- 复习间隔阶梯：1 / 2 / 4 / 7 / 15 / 30 天。
- 「记得」升一阶，「忘了」回到第 1 阶重新排期。
- 卡片按卡组（deck）组织，支持筛选；正面|背面批量导入。

## 模块与排序

- 练习页结构：模块 → 分组 → 考点（三级，两级可折叠）。
- 「金监局专业课」按**科目**分组（不按题型）：计算机系统 / 操作系统 / 计算机网络 / 数据结构与算法 / 数据库 / 程序设计语言 / 经济金融 / 英语，每组 1-4 个考点，考点粒度对齐「考点一~考点二十」讲义，不再做二级细分。
- 模块顺序用户可调（`moduleOrder`），默认：金监局专业课 → 行测 → 申论。
- **考点/分组可删除（隐藏）**：练习页底部「✎ 编辑考点」进入编辑模式，行尾出现「✕ 删除」；删除只隐藏入口、不动题目，页面底部「已删除」区可一键恢复。删除非空考点/分组时需二次确认。
- **同名考点合并**：示例题考点与真题库考点同名时（如「逻辑判断」），只显示一行，题量相加，点击后同时抽示例题与真题；删除该行时两者一起隐藏，恢复时一起出现。
- 推荐学习顺序（玲妈）：资料分析 → 判断推理 → 言语 → 数量；政治理论/申论全程带学，常识最后。

## 目标正确率参考

片段阅读/类比 90%；逻辑填空/定义/图推 80%；资料 ≥90%；数量 ~60%；常识 ~50%；政治理论 70-80%。
